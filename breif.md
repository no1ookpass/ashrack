We are building an open source half rack, modular rack mount system.

All modules wil be half a standard 19" rack, and will be left-or right. They will be slide in trays. 

We want the user in customization to be able to specify very few things, and then print accordingly.

Each side will mount to one side of the rack, and have a "tray" slot, where seperately built components can slide into them.

This breif is only for the mountable front pieces (and their associated tray support), but not for any tray inserts, those will come later.

We should switch left/right with math transformations, rather than a seperate model file

The customizable input for the users should be:

- Module height in rack units, 1, 2, 3, 4 etc
- Tray offset (in mm) from mounting edge
- Tray depth (in mm)
- Tray width (in mm)
